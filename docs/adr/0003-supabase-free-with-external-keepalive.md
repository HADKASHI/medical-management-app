# Supabase Free with an external keepalive

The backend runs on Supabase's free tier (Frankfurt) instead of a paid plan or an always-on server. It was the only free, card-less option covering Postgres, auth, a per-minute scheduler and push sending with little ops work. The cost is that free projects pause after 7 days of low activity, and a paused project silently stops the scheduler, so reminders would just stop. We accept that and guard against it: the per-minute job writes a heartbeat row, and a daily Cloudflare Worker queries the database and emails the owner if the query fails or the heartbeat is stale. A scheduled GitHub Action was rejected for the check because GitHub disables scheduled workflows in repos idle for 60 days. If the app becomes critical or the pause still bites, the move is Supabase Pro (about US$25/month), not a different platform.

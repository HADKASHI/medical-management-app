# Medical Management App

A personal app for tracking medication and medical-supply stock, prescriptions and HMO approvals (Form 17 / התחייבויות), and medical appointments, with Outlook calendar sync, push reminders, and history reports.

See [docs/PRD.md](docs/PRD.md) for the product requirements (Hebrew).

## Status

Planning. Open decisions are tracked as GitHub issues under the `wayfinder:map` issue; the app scaffold comes once the stack decisions are made.

## ⚠️ No real medical data in this repo

This repository is **public**. Never commit or post real medical data here — in code, fixtures, seed files, issues, comments, or screenshots:

- no real medication names tied to a person, dosages, or quantities
- no prescription, Form 17, or approval document numbers
- no real appointment titles, providers, dates, or visit summaries
- no `.env` files, API keys, or tokens

Use made-up examples (e.g. "Medication A, 30 pills") everywhere. Real data lives only in the running app's database, never in git.
